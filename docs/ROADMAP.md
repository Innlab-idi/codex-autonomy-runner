# Roadmap

- **BOOT-01** — contract/bootstrap.
- **ARCH-01** — implementation architecture assessment.
- **ARCH-02** — human approval of the implementation architecture only if ARCH-01 reveals a material decision requiring it.
- **CORE-\*** — incremental implementation.
- **FINALIZER-\*** — safeguarded closure and merge.
- **RUNTIME-\*** — host, adapter, and runtime integration.
- **PILOT-\*** — controlled test repository.
- **ADOPT-\*** — `vevi-exporter` as first real consumer.

The roadmap is directional. It does not authorize opening or executing a checkpoint before its durable dependencies and gates permit it.
